## Sobre o trabalho

O projeto aplica **Arquitetura de Medalhão** e **modelagem dimensional** a um dataset real de
e-commerce brasileiro, cobrindo o ciclo completo: da ingestão do dado bruto à visualização
analítica.

As entregas incluem os scripts de transformação, o DDL de cada camada, os diagramas
entidade-relacionamento, o dicionário de mnemônicos, as consultas de validação do modelo e o
dashboard em Power BI.

## Créditos do dataset

Os dados vêm do
[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce),
publicado pela **Olist** no Kaggle sob licença CC BY-NC-SA 4.0. São cerca de 100 mil pedidos
realizados entre 2016 e 2018, com dados anonimizados.
